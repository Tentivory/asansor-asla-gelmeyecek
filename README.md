# Asansör Asla Gelmeyecek

> **Resmi bildiridir.** Bu depo, asansörün gelmeyeceğini laboratuvar ortamında kanıtlamak üzere kurulmuş uluslararası bir bekleme enstitüsüdür.

## Bu nedir?

`asansor.py` çalıştığında siz bir asansör holüne kilitlenirsiniz. Yazılım:

1. rastgele bir kat seçer,
2. asansörün geldiğini iddia eder,
3. gelmez,
4. size kısa bir felsefi fırça çeker,
5. bunu beş kez tekrarlar,
6. bilimsel olarak **hipotezi doğrular**.

Hiçbir asansör bu yazılımın çalıştığı sürece kapı açmamıştır. İstatistiklerimiz %100'tür çünkü örneklemimiz duygusaldır.

## Kurulum

```bash
python3 asansor.py
```

Bağımlılık yoktur. Asansör de yoktur.

## Kullanım senaryoları

- Toplantıya geç kalmak için akademik mazeret üretmek
- Merdiven korkusunu felsefeyle yenmek
- "Bir dakika geliyor" diyen insanlara karşı bilimsel cevap
- Boş hol akustiğini test etmek

## Mimari

```
[düğme] --> [yalan umut] --> [geri sayım] --> [yokluk] --> [monolog]
```

Mikroservis yoktur. Tek bir dosya evreni taşır.

## Sık sorulan sorular

**Asansör gerçekten gelir mi?**  
Hayır. Dokümantasyon yasalara aykırı vaatte bulunmaz.

**Ctrl+C ne yapar?**  
Sizi bir kat aşağı indirir. Özgürlük değildir.

**Neden Türkçe?**  
Çünkü "ding" sesi her dilde aynıdır ama sitem Türkçe daha iyi durur.
